Calendar Peek

Enable availability inside Slack

Calendar Peek uses Slack’s visible profile email and Google’s read-only Calendar API to show event names and availability. No Slack app or backend is required.

What is authorized

      
Calendar Peek requests calendar.events.freebusy for availability and calendar.events.readonly for event names and start/end times. It does not request descriptions, attendees, locations, or editing access.
