# Calendar Peek

open a coworker's shared Google Calendar from their Google profile card.

![Calendar Peek Slack availability popup](docs/calendar-peek-slack.png)

## install

1. open `chrome://extensions` in a Chromium browser.
2. enable **Developer mode**.
3. click **Load unpacked** and select this folder.

Calendar Peek uses Google's normal calendar search and cannot bypass sharing permissions. It has no analytics, ads, trackers, remote code, or external servers.

See [PRIVACY.md](PRIVACY.md) for the details.
